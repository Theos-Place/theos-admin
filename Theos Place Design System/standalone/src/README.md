# Theos Place — Website UI Kit

Interactive, hi-fi mock of the Theos Place marketing/community website. Built from brand assets (no production code was provided).

## Files

- `index.html` — interactive home → event detail → signup flow
- `Header.jsx` — sticky top nav with logo + links + CTA
- `Hero.jsx` — theta-pattern full-bleed hero with headline + CTAs
- `EventCard.jsx` — event tile (featured & default variants)
- `EventGrid.jsx` — responsive grid of EventCards
- `CommunityBlock.jsx` — full-bleed teal section for "ven como estés"
- `SignupForm.jsx` — inline "apúntate" form
- `Footer.jsx` — navy footer with theta pattern + links

Click the "Apúntate" CTA on any event card to open the signup flow.
